# La 9e chaise

1. Pour lancer l’application, ouvrez `index.html` dans un navigateur. Pour tester le partage et le presse-papiers, servez plutôt le dossier avec un petit serveur statique (par exemple `python -m http.server 8000`) puis ouvrez `http://localhost:8000`.
2. Modifiez tous les dialogues dans `content.js`, dans la liste `steps`.
3. Modifiez les questions et les réponses dans ces mêmes objets `steps`.
4. Remplacez l’image dans `assets/` puis ajustez, si besoin, les références et positions dans `characters`.
5. Renseignez les trois adresses `amazon`, `circle` et `session` dans `content.js`, rubrique `links`.
6. Pour publier, déposez le contenu du dossier sur n’importe quel hébergement de site statique.
